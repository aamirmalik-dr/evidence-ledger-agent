Each document header reads `FICTIONAL EXAMPLE DOCUMENT.` and each manifest records the SHA-256 of every normalized document. Material names such as LX-4, CM-2, RT-1, GZ-9, SX-2, TQ-5, AL-3 and PB-1 are invented, and any resemblance to a real product or publication is unintended.

If an external corpus is ever added, it must first be recorded here with source URL, license, redistribution terms, version, checksum and access date. Material with unclear redistribution rights is not committed.
